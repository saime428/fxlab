图片光标

一行 CSS 换掉光标图形。零 JS、零 rAF、零滞后——它就是系统光标,由合成器画,永远不掉帧。 代价是不能动画:想要放大/变形得换 follower-ring。

把指针移进下面每一格看差别。

实心圆点热点 16 16,圆心对准指针
十字兜底写 crosshair,不是 auto
箭头(40px)兜底 pointer,提示可点
热点写错留默认 0 0 → 圆心偏到指针右下
超尺寸 200px超过 128px 上限 → 整条失效,回落系统光标
不设置系统默认,作对照

全部用内联 data:image/svg+xml:不多一次请求、不会"闪一下才出现"、颜色直接写在里面 (# 要转义成 %23)。

触屏上整个效果不存在,但也无害——不用像跟随类光标那样特意关掉。
配色排版是占位。进项目要跟项目的设计体系走(库规范铁律 6)。
