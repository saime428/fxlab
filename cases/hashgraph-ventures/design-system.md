# Hashgraph Ventures — 设计体系快照

> 取样日期 2026-07-26,方式:浏览器注入遍历 `document.styleSheets` 统计声明频次(30 张表 / 580 条规则,0 张跨域被挡)。
> 用途:糅合原料。抄的是**设计本体**(色/字/节奏),与 pattern 库的"抄机制不抄样式"是互补的两层。

## 取法备注

- 该站**没有 token 体系**,色值/字号写死在各自规则里 → 只能靠频次统计倒推,不能读变量。
- 运行时遍历渲染树取不到东西:文字入场由滚动状态机驱动,内嵌浏览器 pane 冻结时间轴时 DOM 里几乎没有文本(实测 innerText 仅 173 字符)。**读样式表规则对冻结免疫,是更可靠的通道。**

## 色板

| Hex | 用途 | 出现 |
|---|---|---|
| `#000209` | 页面底色(近黑带蓝) | 底 + 遮罩 `rgba(0,2,9,.8)` |
| `#EEEEEE` | 主文字 | 7 |
| `#9BB8E1` | 品牌冰蓝,强调/次文字/色块 | 6 |
| `#B7C6D4` | 三级文字 | 3 |
| `#576676` | 弱化文字/边框 `rgba(...,.35)` | 2 |
| `#5F87B9` | 深蓝色块 | 2 |
| `#E3F4FF` | 高亮近白蓝 | 2 |

**结构**:单一冷色相(蓝)拉出 5 级明度,零对比色。高级感来自"只有一个颜色,但分了五档"。

## 字体与字号

- 三套:`ParaboleWeb`(展示)、`HashgraphWeb`(品牌字)、`NeueMontrealWeb`(正文)
- **根字号是流式的**:`font-size: calc(1000vw / var(--size))`,`--size` 桌面 1440 / 移动 390 → **1rem ≈ 视口宽的 1/144**,整站按画布等比缩放;另有 62.5% / 75% / 80% 三档兜底 → 桌面 **1rem = 10px**
- 阶梯:`0.8 / 1 / 1.3 / 1.4 / 1.6 / 2.4 / 2.8 / 3.2 / 3.6 rem`(即 8–36px),外加 `clamp(Npx, Nrem, Nrem)` 做下限保护
- 字重 **700 一统**(7 处中 6 处),`600` 仅 1 处 → 不靠字重分层,靠字号和明度分层
- 字距 `-0.02em`

## 间距与圆角

- gap:`1rem / 1.6rem / 2rem / 3.2rem`(10/16/20/32px)
- 圆角 `0.5rem` = 5px,**几乎是直角**

## 运动(本站最值钱的一项)

| | 值 | 频次 |
|---|---|---|
| 主时长 | `0.6s` | 39 |
| 次时长 | `0.8s` | 17 |
| **主缓动** | `cubic-bezier(.14, 1, .34, 1)` | **47** |
| 遮罩缓动 | `cubic-bezier(.9, 0, .1, 1)` | 7 |
| 线性 | `linear`(marquee/进度类) | 11 |

**全站"顺滑"的单一来源就是那条 `cubic-bezier(.14,1,.34,1)`** —— 强 ease-out(起步猛、收尾极缓),47 次覆盖压倒一切。次曲线 `(.9,0,.1,1)` 是强对称 ease-in-out,只用在遮罩这类"要有重量"的东西上。两档时长 × 两条曲线,整套运动语言就这么点内容。

## 可糅合性

- ✅ **搬得走**:缓动曲线 + 两档时长(纯数值,零依赖)、单色相五级明度的色板结构、字重不分层的排版策略
- ⚠️ **有陷阱**:rem 基准是 10px 且随视口流动,rem 数值搬到 16px 根的站上全部要 ×1.6
- ❌ **搬不走**:首屏那块发光晶体是 canvas 渲染,不在 CSS 里(见 [analysis.md](analysis.md) 运行时实测)
